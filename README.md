# Educational Power BI Report

## Examination Report

An interactive Power BI dashboard developed to analyze student performance in the Examination. The report provides insights into student participation, class-wise performance, rankings, and subject-wise scores.

## Project Overview

This project focuses on transforming raw examination data into meaningful insights through interactive data visualization and analytics.

### Dashboard Pages

- **Executive Overview:** Overall examination KPIs and student participation insights.
- **Class & Subject Performance:** Class-wise and subject-wise performance analysis.
- **Student Leaderboard:** Student rankings and score-based analysis.

## Key Insights

- Total student participation
- Class-wise student distribution
- Highest and average examination scores
- Inside vs. Outside lead type analysis
- Student ranking analysis
- Subject-wise performance insights

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Cleaning
- Data Visualization
